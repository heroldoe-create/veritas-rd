# Changelog

## v4.0.0

- The boundary with skill/prompt auditing was corrected: that job (does a skill live, die or get rewritten) belongs to a different skill; Veritas acts as its evidence layer when claims must be checked against sources.
- Mandatory read-proof per source in the inventory: exact file or URL and a read locator.
- Sources added mid-task get the next free ID; existing IDs are never renumbered.
- A single label for knowledge taken from model memory: `[PARAMÉTRICO — no anclado]`.

*(Spanish)* La frontera con la auditoría de skills/prompts se corrigió; prueba de lectura obligatoria por fuente; las fuentes añadidas a mitad de tarea reciben el siguiente ID libre sin renumerar; etiqueta única para el conocimiento de memoria.
